# Lib — Documentation

The `lib/` folder contains shared infrastructure used across the entire app:
API client configuration, TypeScript types, and utility helpers.

## Files Index

| File | Description |
|------|-------------|
| [api-client.md](./api-client.md) | Axios instance, request/response interceptors, token refresh |
| [types.md](./types.md) | Shared TypeScript type definitions |
| [api-types.md](./api-types.md) | Auto-generated OpenAPI types (do not edit manually) |
| [chart-utils.md](./chart-utils.md) | Recharts data transformation helpers |
| [report-export.md](./report-export.md) | XLSX/CSV export utilities |
| [socket-events.md](./socket-events.md) | Socket.IO event name constants |
| [styling.md](./styling.md) | Shared CSS class utility helpers |
| [utils.md](./utils.md) | General utility functions (cn, etc.) |

## Types Subfolder

The `lib/types/` folder contains hand-written TypeScript type definitions:

| File | Contents |
|------|----------|
| `index.ts` | Re-exports + pagination/query types |
| `invoice.ts` | Invoice, ListInvoice, MyInvoice, InvoiceDetail, ReviewPayload |
| `user.ts` | User, CreateUserRequest |
| `organization.ts` | Organization types |
| `primitives.ts` | Shared primitive types (status enums, etc.) |

> [!NOTE]
> `api-types.ts` in the root of `lib/` is **auto-generated** by `openapi-typescript` from the backend OpenAPI spec.
> Run `pnpm run generate-types` (or equivalent) to regenerate it. Do not edit this file manually.
